# HobbyHub Implementation Plan

> **For agentic workers:** Use the current-session execution workflow task by task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** Deliver a separate, demonstrable HobbyHub forum with a Supabase-ready database, all required features, and submission materials.

**Architecture:** A React single-page app uses one repository interface with localStorage and Supabase implementations. Anonymous Supabase users can read the shared forum, while RLS restricts post edits and deletes to their authors. An RPC increments upvotes atomically.

**Tech Stack:** Vite 8, React 19, React Router 7, Supabase JS 2, Vitest 4.

**Spec:** `docs/superpowers/specs/2026-11-13-hobbyhub-design.md`

## Global constraints

- Keep Project 7 intact.
- The feed displays only creation time, title, and upvote count per post.
- Title required; body and external image URL optional.
- Every upvote click adds one; repeat clicks are allowed.
- Keep repository private and add `codepathreview` before submission.

## Review focus

- Invalid or whitespace-only titles must not create posts.
- Search must match titles without case sensitivity and sorting must handle ties consistently.
- A deleted post's detail URL must show a clear missing state.
- Repeated clicks must not lose upvotes due to stale state or non-atomic cloud writes.
- Browser storage with malformed data must recover without crashing the app.
