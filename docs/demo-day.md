# Formline: three-minute Demo Day outline

No slide deck is needed. Open the app at the home feed before speaking. Keep one short post idea and image URL ready to paste.

| Time | Show | Say |
| --- | --- | --- |
| 0:00–0:25 | Home page and design-focused feed | “Formline is a place for people who enjoy designing cars to ask questions, share concepts, and get feedback.” |
| 0:25–0:50 | Search for “lighting”; switch between newest and most upvoted | “The feed keeps the focus on titles, dates, and upvotes. I can search titles and sort by recency or popularity.” |
| 0:50–1:25 | Create a post with a title, short body, and image URL | “A title is required. The explanation and reference image are optional.” |
| 1:25–2:05 | Open its detail page, upvote twice, and add a comment | “The detail page holds the full discussion. Each upvote click counts, and comments make feedback visible.” |
| 2:05–2:35 | Edit the new post, then return to its detail page | “The browser identity marks my own posts, so I can correct or refine an idea after publishing.” |
| 2:35–2:50 | Delete the post and show the feed | “I can also remove a post and its comments when I no longer want the discussion.” |
| 2:50–3:00 | Point to the status badge | “This demo saves in this browser. The project also includes a Supabase schema and adapter for a shared forum.” |

If a live Supabase project has been configured and verified, say that the status badge shows **SUPABASE LIVE** and briefly show the same post in another browser. Otherwise, use the Browser Demo flow and describe the cloud integration as ready to connect.
